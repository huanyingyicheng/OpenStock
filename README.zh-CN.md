# OpenStock（中文说明）

OpenStock 是一个基于 Next.js 的开源行情/资讯查看应用（不是券商，也不提供交易功能）。本仓库包含可直接运行的便携版打包脚本，并提供 **资金流排行与趋势图**（支持 A 股 / 美股 / 港股；板块目前以 A 股为主）。

> 免责声明：本项目仅用于信息展示与学习研究，不构成任何投资建议。行情/资金流等数据可能延迟或受数据源规则影响。

---

## 1. 快速开始（推荐：便携版）

便携版的目标：解压/双击即可运行，不要求你先配置数据库或账号。

### 1.1 运行（Windows）

1. 解压 `OpenStock-portable.zip` 到任意目录（例如 `E:\Users\username\OpenStock-portable-fixed`）
2. 双击 `run.cmd` 启动
3. 浏览器会自动打开（默认：`http://127.0.0.1:3000/flows`），也可以手动打开：`http://127.0.0.1:3000`

语言：默认会根据浏览器语言自动选择（中文浏览器默认中文），也可以在右上角切换。

### 1.2 “网站不安全/打不开”是什么情况？

- `run.cmd` 启动的是本地 **HTTP**：`http://localhost:3000`  
  浏览器显示“不安全”是正常的（因为没有 HTTPS 证书），并不代表项目有病毒或会把你登录到别处。
- 如果你开启了浏览器的 “HTTPS-Only / 总是使用安全连接”，它可能会把 `http://localhost:3000` 强行升级成 `https://localhost:3000` 导致打不开。  
  解决：关闭 HTTPS-Only，或手动输入 `http://localhost:3000`。

## 2. 主要功能（你关心的）

### 2.1 A 股搜索（支持 6 位代码/中文名）

在顶部搜索框中可输入：
- `600519` / `贵州茅台`
- `SSE:600519`、`SZSE:000001`

### 2.2 资金流排行（板块/个股）

打开：`/flows`

支持：
- **市场选择**：A 股 / 美股 / 港股（右侧“市场”下拉框）
- **板块排行**：行业 / 概念 / 地域（板块目前主要为 A 股）
- **个股排行**：A 股（沪深A、沪A、深A、科创板、创业板、中小板）/ 美股 / 港股
- **基金（ETF）排行**：沪深 ETF 资金流
- **场外基金**：可在“基金”Tab 中切换“场外基金”，查看净值/涨跌幅（场外基金通常没有资金流向/趋势图口径）
- 排序指标：**成交额**、**净流入额**、主力流入/流出、超大单净额、大单净额等
- 周期：今日 / 3日 / 5日 / 10日
- 排序：升序 / 降序

更多：
- 板块行内可点进板块详情：`/flows/sector/BKxxxx`（包含成分股排行 + 相关基金链接）
- 资金趋势页：`/flows/trend`（日/周/月；日支持 1/3/5 滚动）

#### 2.2.1 3 日、5 日的“流入/流出”数字代表什么？

- **周期（今日/3日/5日/10日）**：表示“最近 N 个交易日”的资金净额合计（数据源字段不同，但含义都是主力净流入净额的时间窗口）。
- **净流入**：带正负号的“主力净流入净额”（正数=净流入，负数=净流出）。
- **主力流入 / 主力流出**：为了更直观，本项目把“净额”拆成两列显示：
  - 若净流入 > 0：主力流入 = 净流入，主力流出 = 0
  - 若净流入 < 0：主力流入 = 0，主力流出 = -净流入（取绝对值）

> 提示：这是“净额拆分展示”，不是两条独立的原始“流入/流出”口径。

数据源说明：
- 资金流排行由服务器端接口拉取（当前实现为东方财富公开数据接口聚合结果）。
- 不同市场的金额单位以数据源返回为准（A 股常见为人民币口径，美股/港股为对应市场币种口径）。

#### 2.2.2 趋势图（A 股 / 美股 / 港股）怎么用？

- 趋势页：`/flows/trend`
- 输入示例：
  - A 股：`SSE:600519`、`SZSE:000001`
  - 美股：`US:AAPL`
  - 港股：`HK:00700`

> 说明：场外基金通常不支持资金流趋势图，因此不在趋势页提供。

## 3. 账号/登录相关（可选，不需要也能用）

### 3.1 “创建账号没反应 / missingEnv”为什么？

登录/注册功能基于 Better Auth + MongoDB，需要你提供以下环境变量：
- `MONGODB_URI`：MongoDB 连接串（示例：`mongodb://127.0.0.1:27017/openstock`）
- `BETTER_AUTH_SECRET`：随机长字符串（建议 32+ 字符）
- `BETTER_AUTH_URL`：你实际访问的地址（本地：`http://localhost:3000`）

如果未配置或 MongoDB 没启动：
- 登录/注册会提示“账号功能未配置”
- 但 **搜索/资金流排行/股票页面仍可使用**

### 3.2 会登录到其他地方吗？不登录会影响真实数据吗？

- 不会“登录到其他地方”。账号体系只会连接到你配置的 `MONGODB_URI`（通常是本机 MongoDB）。
- 不登录不会影响任何“真实交易数据”：本项目不提供交易，仅做展示，数据源为第三方行情/资金流接口或小组件。

## 4. 黑屏/空白页面排查

### 4.1 首页 TradingView 小组件黑屏

这通常不是程序崩了，而是：
- 当前网络无法访问 TradingView 资源，或被代理/防火墙拦截

解决建议：
- 先使用 `/flows`（资金流排行）或顶部搜索功能
- 如果需要小组件，换网络/放行 `tradingview.com` 相关域名

### 4.2 启动脚本双击没反应

建议用命令行启动以看到报错：

```bat
cmd /k "cd /d <解压目录> && run.cmd"
```

常见原因：
- Windows 没有关联 `.cmd` 的默认打开方式
- 杀毒软件拦截脚本执行
- 端口被占用（默认 `3000`）

端口修改：在命令行里先设置 `PORT` 再运行（例如 3100）：

```bat
set PORT=3100
run.cmd
```
